# Backroom Games

Browser board games for a group of friends. Create a room, share the code, and
everyone plays from their own browser. The first game is **Corners**.

## Quickstart

With Docker:

```sh
docker compose up --build   # http://localhost:3000
```

With Node 24 and pnpm:

```sh
pnpm install
pnpm dev                    # http://localhost:5173
```

To test multiplayer, open the game in a normal window and a private window.

See [CONTRIBUTING.md](CONTRIBUTING.md) to work on it.
